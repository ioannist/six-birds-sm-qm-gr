# Part I — Framework identity, authority, and anti-reductionist orientation

### 1. ★ Framework identity
**Model answer:**

`[AUTHOR THESIS]` SBT is both the meta-map over closure ladders and the generative engine of layer formation through P1–P6. As map, it identifies layers, lenses, closures, obstructions, lawful ascents, and descending shadows. As generative engine, its six primitives are the closure-changing mechanics by which a run constructs, tests, promotes, and audits new layer objects. It is not a black-box oracle that outputs arbitrary content or values without a lawful run.

**Grounding:** Anti-Reductionism Primer; Foundations I, especially the theorem that P1–P6 arise as closure mechanics; Foundations II–III; author’s settled clarification.

### 2. ★ Universality thesis
**Model answer:**

`[AUTHOR THESIS]` The universality claim is the framework-level thesis: all reality and all genuine emergence occur through SBT; nothing real escapes its closure/layer grammar. It is **not** a theorem proved by Foundations I. Foundations I proves scoped structural results under stated hypotheses. Its theorem-hygiene does not negate the framework thesis, but the thesis must not be cited as a theorem of that paper.

**Grounding:** Author’s settled clarification; Foundations I scope statements; corpus-wide cross-domain program.

### 3. ★ Primer reconciliation
**Model answer:**

The primer’s “neither engine” line distinguishes SBT from the two concrete climbing modes—mechanical run and imagination—and rejects the idea that the map itself is a black-box content generator. It should not be generalized into “P1–P6 are not generative mechanics.” The author’s settled interpretation is that SBT is the meta-map **and** the generative closure engine, while a particular run or imaginative proposal supplies the contingent content traversed and then audited.

**Grounding:** Anti-Reductionism Primer, “Two engines, one map”; Foundations I’s canonical P1–P6 closure mechanics; author clarification.

### 4. ★ Authority order
**Model answer:**

The paper governs theorem/definition claims; running code governs what the implementation actually computes; author-set statements govern framework identity and thesis; syntheses and memories are secondary. Report the conflict explicitly with evidence grades. Do not harmonize it by silently rewriting a theorem, code fact, or author thesis.

**Grounding:** Primer; grounding-system authority discipline; audit methodology across the corpus.

### 5. Inside versus between layers
**Model answer:**

Inside a closed layer, ordinary derivation and the layer’s native mathematics govern. SBT speaks primarily at boundaries: closure failure, package change, strict extension, promotion, and lawful descent. Calling an internal calculation “a relabeling” may be true because SBT does not replace native within-layer derivation; it is irrelevant to whether the layer itself was lawfully constructed or whether a promoted carrier was essential.

**Grounding:** Anti-Reductionism Primer, within-layer versus between-layer distinction.

### 6. The two climbing modes
**Model answer:**

The two modes are a mechanical run and imagination/search that posits a candidate extension. In both, SBT maps the rung, specifies admissibility, tests strictness, controls false positives, and audits descent. A posited object is not accepted merely because it was imagined; it must survive the same closure and audit obligations.

**Grounding:** Anti-Reductionism Primer.

### 7. Framework thesis versus formal theorem
**Model answer:**

A formal paper’s disclaimer limits what that paper proves. It does not automatically define the whole framework’s identity. Conversely, the framework thesis cannot be promoted into `[THM]` without proof. The correct record is: `[AUTHOR THESIS]` universality; `[THM]/[SCOPED RESULT]` only for the paper’s named assumptions and conclusions.

### 8. Territory versus map
**Answer:** False.

An SBT description is a candidate map or grammar. It becomes a territorial claim only when the substrate, package actions, obstruction, promotion, controls, and any value descent are actually constructed and audited.

**Grounding:** Primer’s “using the map is not asserting the territory”; Foundations II admissibility discipline.

### 9. Run irreducibility
**Model answer:**

If one base-level formula already determined every future extension, each extension would factor through the base description. It would therefore be definable from below and not strict. The no-shortcut claim is about nonfactorization across the declared interface, not mystical incomputability.

**Grounding:** Primer; Foundations I definability; Cantor strict-extension paper.

### 10. Black-box prover
**Model answer:**

Generative means SBT provides lawful closure-changing operations and a run discipline. It does not mean “enter a question, receive the correct theorem or mass.” Content must be generated by an instantiated substrate, package actions, controls, promotion, and audit.

### 11. Reductionist failure modes
**Acceptable examples:**

- Treating emergence as more iterations of one fixed completion → require package change.
- Reading a known invariant from an injected operator → reject as recovery/smuggling.
- Replacing a joint higher-context distinction with a lower hidden record → classify as currentization/overread.
- Treating event obstruction as the only strict register → use the typed strict-test appropriate to the claim.
- Treating a feasible tiny setup as a universal no-go → record the scoped verdict and search another lawful layer/interface.
- Treating a paper’s scoped modesty as refuting the framework thesis → keep theorem and thesis evidence grades distinct.

### 12. Evidence-grade classification
**Answers:**

1. False claim; contradicted by `[THM]/[DEF]` guardrails: P3 alone is not directionality.
2. `[THM]` or `[SCOPED RESULT]`, depending on the exact statement, under the Cantor assumptions.
3. Unsupported; not a theorem. At best an invalid extrapolation from `[AUTHOR THESIS]`.
4. `[CODE FACT]` for that instance.

# Part II — The six primitives, closure, and layer mechanics

### 13. ★ P1–P6
**Model answer:**

- **P1 — operator rewrite:** change/rewrite the dynamics when a macro law fails to descend or another lawful rewrite is required.
- **P2 — gating/constraints:** restrict feasibility, support, or representability.
- **P3 — autonomous protocol holonomy/route mismatch:** compare noncommuting lawful routes with protocol state internalized.
- **P4 — sectors/staging/invariants:** supply the refinement stage, sector structure, or theory index.
- **P5 — packaging:** apply an idempotent completion whose fixed points are packaged objects.
- **P6 — accounting/audit:** provide monotones, ledgers, certificates, costs, and no-overread controls.

**Grounding:** Foundations I, definitions of P1–P6 and meta-primitives theorem.

### 14. ★ P3 and directionality
**Model answer:**

P3 detects route mismatch. Reversible autonomous systems can show apparent route effects when protocol state is hidden. An arrow claim needs an honest P6 audit—such as affinity, path-reversal asymmetry, or entropy-production structure—with protocol/phase included in the state. The slogan is “P3 needs P6_drive” under the named autonomy assumptions.

**Grounding:** Foundations I; Protocol Trap paper.

### 15. P5 packaging
**Model answer:**

P5 is an idempotent endomap/completion. Its fixed points are the packaged objects of the layer. A quotient or lift may implement the packaging, but objecthood is closure under the declared completion, not merely a label.

### 16. A theory layer
**Model answer:**

A layer consists of an observation/lens defining visible equivalence, a completion or packaging operation, the resulting fixed-point objects, native laws that descend on them, and audits specifying what is preserved or spent. Exact and approximate closures require their own defect discipline.

### 17. ★ Saturation
**Model answer:**

A fixed idempotent completion satisfies repeated-application saturation: after closure, further applications do not create new definability. New strict content requires changing the package, lens, admissibility structure, operator, or theory language—not just repeating the same completion.

**Grounding:** Foundations I closure saturation; Cantor paper; incompleteness/package-change paper.

### 18. Completion versus extension
**Model answer:**

Completion closes objects under a fixed rule and remains within the same definability structure. Extension adds a distinction or object not definable through the base map, changing the theory’s expressive/closure structure.

### 19. Cantor-shell mechanism
**Model answer:**

`[THM]/[SCOPED RESULT]` On the audited Cantor shell, under the paper’s assumptions, fixed completion saturates; P5-generated package material forces refinement of the P4 theory index; failure of an induced macro law supplies a macro-admissibility obstruction and strict extension. This is a proven mechanism for that construction, not a universal recipe for every SBT instance.

**Grounding:** Strict Theory Extension on a Lawful Continuous Cantor Shell.

### 20. Material P4←P5 forcing
**Model answer:**

P5-produced objects or distinctions force the active theory/stage record P4 to refine because the old language cannot support the required law. It is material only if subsequent dynamics, admissibility, or readout actually use the new record. A field added only to logs or labels is descriptive metadata, not a rung.

### 21. P2 gating
**Model answer:**

P2 declares which states, transitions, or representations are feasible at the current interface. Feasibility is layer-relative because it depends on the current support, budget, lens, constraints, and lawful operations.

### 22. P6 accounting
**Model answer:**

P6 can track cost, information loss, monotones, audit boundaries, provenance, and directionality evidence when the needed assumptions hold. P6 alone does not prove novelty, strictness, or a thermodynamic arrow.

### 23. P1 rewrite
**Model answer:**

A micro-update descends only if equivalent microstates remain equivalent after update. If not, lawful responses include refining/promoting the state, rewriting the operator, changing the interface/package, or abandoning the claimed closed macro law. Silently choosing representatives is not lawful.

### 24. Bounded interface
**Model answer:**

Bounded interface is an explicit hypothesis or target-side result, not a consequence of refinement, strictness, or SBT universality. It must be verified for each construction and may fail.

**Grounding:** Foundations I bounded-interface discussion.

# Part III — Definability, strict extension, and typed obstruction registers

### 25. ★ Definability equals factorization
**Model answer:**

An object/map `h` is definable from the base theory map `f` when there exists `h̃` such that

`h = h̃ ∘ f`.

The base-visible equivalence therefore determines the higher object.

**Grounding:** Foundations I.

### 26. Strict witness
**Model answer:**

Find `x,x'` with the same base image but different extended image:

`π₀(x)=π₀(x')` and `π₁(x)≠π₁(x')`.

Then no `φ` can satisfy `π₁=φ∘π₀`.

### 27. The factorization defect
**Model answer:**

A nonempty defect certifies nondefinability/strictness for the declared maps and interface. It does not automatically prove promotion, closure, value descent, computational usefulness, directionality, or global event obstruction.

### 28. Fixed-package failure versus package change
**Model answer:**

A defect or incompleteness inside one fixed package may merely show that the package is inadequate. A new layer requires a lawful new package/language/object structure, with strictness and promotion audited.

### 29. No-shortcut meaning
**Model answer:**

No lower-interface map reproduces the higher distinction. This is a typed factorization statement. It does not prohibit all meta-level proofs, simulations, or descriptions of the construction.

### 30. Finite forcing rarity
**Model answer:**

Under the finite partition model and its sampling assumptions, uniformly sampled predicate extensions are overwhelmingly nondefinable when hidden volume exists. The result is a counting theorem for that distribution, not a theorem that every naturally arising extension is rare in the same way.

**Grounding:** Foundations I finite forcing section.

### 31. ★ Event obstruction is not the universal definition
**Answer:** False.

Accepted strict tests include set-map nonfactorization, predictive current-equal/future-distinct witnesses, failure of an induced macro law/closure deficit, scoped Cantor macro-admissibility obstruction, and other accepted fixed-support tests. Event-package nonextendability is one strong local-to-global register, not a universal prerequisite.

**Grounding:** Accepted New-Layer Strict Tests; Holonomy; Cantor; No-Go Theorems.

### 32. Typed registers, not blanket equivalence
**Model answer:**

They are typed manifestations of lost factorization, closure, adequacy, or realization in different mathematical categories. One may build bridge theorems between particular registers under explicit assumptions. Without such a theorem, do not call them universally equivalent or interchangeable.

### 33. Closure deficit
**Model answer:**

If the claimed lower state cannot support a representative-independent induced update while a refined state can, the nonclosure can certify a transition strict extension. Controls must exclude generic coarse-graining non-Markovity, hidden protocol state, insufficient continuation saturation, finite-sample error, and decoupled/null cases.

### 34. Currency/residual register
**Model answer:**

A residual measures a typed inadequacy, spent budget, or unclosed component. It can guide package change or certify failure under a theorem’s assumptions. It is not automatically a scalar answer, a strictness witness, or a universal “currency” outside the declared layer and audit.

### 35. Obstruction as certificate
**Model answer:**

The obstruction shows the old package cannot lawfully realize the required object/law. Removing it by weakening the claim, exposing forbidden information, or changing the object destroys the certificate. The constructive response is promotion/package change, not blind minimization to zero.

### 36. Certificate versus recovery
**Model answer:**

Recovery starts with an answer-bearing object or operator and shows packaging preserves or re-extracts its known invariant. Strict extension first computes a nonfactorization/obstruction without the answer, promotes a new carrier, and only then allows an audited held-out descent.

# Part IV — Locally Boolean event packages and empirical identity

### 37. Locally Boolean, globally obstructed
**Model answer:**

Each context has a Boolean event algebra over its local atoms. Global obstruction means no admissible common package can realize all contexts and accepted shared-event identities while covering every required atom.

### 38. Contexts, atoms, and events
**Model answer:**

An atom is one stable outcome class in a context. An event is any subset/union of atoms. Restricting to singleton events can miss genuine empirical identities that appear only after lawful aggregation.

### 39. ★ Empirical identity
**Model answer:**

Two events are empirically identical when all admissible downstream probes licensed by the relevant bridge laws give the same public response. Labels, member lists, or microscopic decompositions are not the identity criterion. Equal support preimages are sufficient for an extensional identity but not necessary for a genuine empirical one.

**Grounding:** Locally Boolean, Globally Obstructed; event discovery code.

### 40. Aggregate before probing
**Model answer:**

For an event, first sum/integrate all member contributions into the event-conditioned boundary response. Then apply the law-specific probe and compare exact subnormalized responses. Probing members individually and hashing their decomposition overreads the substrate.

### 41. Coarse probe versus full-record overread
**Model answer:**

A too-coarse probe omits load-bearing information and manufactures false identities and spurious obstruction. A too-fine probe retains microscopic decomposition/member IDs, prevents legitimate response coincidences, and manufactures spurious feasibility.

### 42. Quotient-feasibility audit
**Model answer:**

It forms candidate global atoms from joint context signatures on common support, removes classes violating accepted identities, and checks that survivors are nonempty and cover every context atom. Feasible means at least one admissible globally covering realization remains.

### 43. Structural exact solver
**Model answer:**

It is an independent small-instance baseline/comparator. For same-support empirical-identity claims, the quotient backend is the decisive package-native path. Agreement strengthens confidence; disagreement requires diagnosis.

### 44. ★ Hidden-record discipline
**Model answer:**

A control may expose omitted records that are stage-available, context-admissible, provenance-licensed, and preserve the same formal object. It may not give a branchwise context a joint Wilson loop, recombination result, or future completion that exists only at a higher context. Doing so changes the package rather than auditing hidden residue.

### 45. Currentization versus artifact removal
**Model answer:**

Currentization enlarges the lower/current interface so a formerly hidden distinction becomes visible. The original nonfactorization relative to the original interface remains genuine. Artifact removal instead exposes a record that was lawfully already part of the same object but accidentally omitted.

**Grounding:** Holonomy with Memory; Hiddenness; event-package controls.

### 46. False-positive controls
**Model answer:**

A same-object control preserves support, claim, context semantics, accepted proposal surface or canonical transport thereof, and backend. Principal families include hidden-record, flattening/completion, protocol internalization, null/decoupled controls, and robustness/noise. “Not applicable” means no intervention preserves the same formal object; it is not a pass.

### 47. ★ Real engine versus bespoke driver
**Model answer:**

The real package actions generate contexts from a frozen substrate; bridge-law inference generates shared events; the authoritative solver computes infeasibility; controls rerun the same pipeline. A script that hard-codes K/R labels, parity, a witness, or a known result is not the engine result even if it calls a solver afterward.

# Part V — Holonomy, memory, predictive quotients, and transport

### 48. ★ Current quotient versus predictive quotient
**Model answer:**

`Q` identifies histories with the same current visible record. `M` identifies histories only when all admissible future continuations and readouts agree. There is a natural map from the finer predictive classes to the current classes.

### 49. Predictive strict-refinement witness
**Model answer:**

`q(h)=q(h')` but some lawful future continuation/readout separates them. This proves that predictive equivalence strictly refines current equivalence and that current state is not future-sufficient.

### 50. ★ Predictive minimality
**Model answer:**

Among abstractions sufficient for the declared future-observable and continuation family, the predictive quotient is the coarsest/minimal one: any other future-sufficient abstraction factors through it on the relevant reachable image. The result is relative to the frozen interface, continuation catalog, protocols, and readouts—not all logically imaginable probes.

**Grounding:** Holonomy with Memory.

### 51. Admissible continuation family
**Model answer:**

If a complete physical slab operation is a weighted sum of internal terms, the interface may not lawfully select one term. Treating each summand as an action gives the predictor extra microscopic control and can make the quotient artificially discrete. Continuations must be physical/protocol-admissible.

### 52. Native predictive transport
**Model answer:**

Define `T_z([h]_M)=[z⋆h]_M`. It is lawful only if equivalent representatives always land in the same predictive class for every admissible continuation.

### 53. Protocol trap
**Model answer:**

Apparent holonomy or irreversibility can arise because an external schedule/protocol variable was hidden. Internalizing protocol state may restore autonomous closure or reversibility. Arrow claims must be audited on the enlarged autonomous system.

### 54. Transport-null versus mass-bearing
**Model answer:**

A transport-null distinction changes realization/provenance but maps to the same complete future transport response. A mass-bearing distinction must be essential to the projective channel transport or dominant visible sector: ablating it changes or destroys the lawful decay structure, not only a label or normalization.

### 55. Static packageability with transition strictness
**Model answer:**

Yes. A global set may realize all static event identities while no induced update descends to the current quotient. Event realization and dynamic closure are different registers.

### 56. Dominant root non-implication
**Model answer:**

Predictive refinement may preserve transient, overlap, route, or subdominant information while all states share the same leading root. Root separation requires additional autonomous-sector or observability hypotheses.

# Part VI — Promotion, exactification, and active layer formation

### 57. ★ Promotion gates
**Model answer:**

- **Suf:** sufficient for the declared observables/tasks.
- **Clos:** induced operations are representative-independent and land in the carrier.
- **Stab:** survives further admissible quotienting/refinement; no redundant unstable coordinate.
- **Ctrl:** passes applicable false-positive and null controls.
- **Hon:** honest provenance, no smuggling, no forbidden access.
- **Leg:** the new coordinate is legible in the claimed law/task rather than decorative.

**Grounding:** Promotion Criteria.

### 58. Class-to-class transport
**Model answer:**

A response-image ID may describe an output but does not prove the next state is an object of the same carrier. Native law requires `T:U→U`, with actual target classes and closure under repeated composition.

### 59. Genuine fixed-point refinement
**Model answer:**

Refine using current observations and the successor **class signatures** under every admissible continuation, then iterate until the partition stabilizes. If the future vector is already in the key, checking equal future vectors inside a class proves nothing new.

### 60. Response descriptor versus carrier
**Model answer:**

A descriptor groups states by one response table. A carrier supports its own state identity, native transport, readout, composition, and audit across repeated lawful operations.

### 61. Carrier exactification
**Model answer:**

Exactification reduces a promoted candidate to the minimal behavioral object that actually supplies the declared state/readout/transport roles. Decorative, duplicative, or lower-replaceable coordinates are quotiented away.

### 62. Second-stage stability
**Model answer:**

After promotion, ask whether another lawful quotient or completion removes the promoted distinction while preserving all declared laws and tasks. If so, the first candidate was not the surviving carrier.

### 63. Material forcing after promotion
**Model answer:**

Subsequent updates must consume and produce the promoted classes. If the old lower record still drives all computation and the new class appears only in logs, no active layer birth occurred.

### 64. Layer stacks and branches
**Model answer:**

No. The corpus permits towers, common rungs, sibling identity axes, and branched stacks. A structural/audit branch, a scale/compression branch, and a run/value branch may diverge and later reconnect, each with its own strictness and audit obligations.

**Grounding:** Strict Test to Event Package Admissibility; To Kill Three Stones; To Spend a Stone; Institutions paper.

# Part VII — SAU, non-descending objects, and lawful value landing

### 65. ★ SAU pattern
**Model answer:**

`U` is non-descending through the lower quotient/interface, while a selected expression `C(U)` lawfully descends to a lower-visible accepted answer `a♯`:

`U ↛_q`, `C(U) ↓_B a♯`.

The value may descend; the promoted support and its essential role do not collapse into the lower layer.

**Grounding:** The Usefulness of Non-Descending Objects / Why Mathematics Even Works.

### 66. ★ Essential Boundary Necessity
**Model answer:**

After removing irrelevant nodes, some promoted hidden support must lie in the final answer’s dependency cone. No audit-preserving deletion or replacement by lower-visible data may preserve the same interface, answer, admissible lower rules, and audit status. Otherwise the promoted object is decorative.

### 67. Conventional value equality
**Model answer:**

Yes. Physical correctness requires agreement with the ordinary finite-lattice gap. It is lawful only if the accepted derivation genuinely depends on the non-descending carrier and no admissible lower-visible replacement under the frozen profile supplies the answer.

### 68. Projective MBO
**Model answer:**

Projective MBO tests whether obstruction-forced distinctions affect the correlator’s decay law modulo overall amplitude, ideally the dominant visible sector. It is a strong mass-specific project gate. SAU essentiality is broader and is defined by dependency and replacement under the full frozen profile.

### 69. No smuggling
**Acceptable examples:**

- Supplying a dense answer-bearing transfer operator.
- Supplying eigenvalues/eigenvectors or a Perron state.
- Fitting a known late-time tail during construction.
- Using the benchmark mass in class selection, truncation, stopping, or root choice.
- Encoding a known parity/recoupling result as a literal label.
- Letting held-out comparator information influence the package.

### 70. Out-of-sample validation
**Model answer:**

Freeze the carrier grammar, package actions, source/readout, root rule, tolerances, and audit before validation. Hold out later depths, parameter points, geometries, protocols, or benchmark values not used to construct or select the package.

### 71. Sealed comparator
**Model answer:**

A full-resolution or conventional comparator is legitimate after the SBT artifact is frozen. Its values, state multiplicities, root selection, thresholds, and implementation hints must not feed back into construction.

### 72. Budget-relative essentiality
**Model answer:**

Under a frozen local-input and P6 budget profile, lower methods may fail or exceed budget while the promoted carrier constructs and evaluates the same scalar within budget. The scalar descends, but the accepted computational trace essentially requires the non-descending carrier.

### 73. ★ Lower-profile saturation
**Model answer:**

The profile must declare the base theory, input instrument, visible data, allowed algorithms/candidate class, hardware/time/memory/precision budget, accepted answer type, error threshold, audit requirements, and nonclaim register. Lower saturation must range over every lawful competitor under that same profile, not only a convenient straw man.

**Grounding:** SAU lower profile/saturation; P/NP under Closure.

# Part VIII — Integrated diagnosis and research judgment

### 74. Raw-transfer bypass
**Model answer:**

Strictness may remain established structurally, but the value trace fails SAU essentiality because the root bypasses the promoted carrier. The scalar is a conventional lower computation with decorative SBT metadata until the dependency path is repaired and replacement is excluded.

### 75. Event package feasible, closure deficit positive
**Model answer:**

Record both:

- local-global event register: globally packageable;
- transition/macro-admissibility register: strict extension if the induced law genuinely fails on `Q` and closes on `M` with controls.

Do not force one register to imitate the other.

### 76. ★ Author thesis versus paper scope
**Model answer:**

`[AUTHOR THESIS]` SBT is the universal generative engine/grammar of reality. `[THM]` Foundations I proves only its stated closure and primitive results under assumptions and explicitly does not prove emergence in every system. The scope disclaimer limits theorem attribution; it does not annul the author’s framework thesis.

### 77. Full-record bridge signature
**Model answer:**

It overreads microscopic decomposition and collapses empirical identity into extensional identity. Replace it with the exact additive, subnormalized, tomographically complete public boundary response for the applicable bridge law, aggregating the event before comparison.

### 78. Discrete exact predictive carrier
**Model answer:**

No contradiction. Holonomy minimality allows the coarsest future-sufficient carrier to be discrete if the declared future interface separates every state. Bounded interface was never guaranteed. Next audit continuation admissibility, weighted rather than termwise actions, task-specific observable surfaces, approximate/defect-controlled higher layers, and scaling.

### 79. ★ Feasible or negative run under the universality thesis
**Model answer:**

Accept the scoped result honestly: this package/layer/interface did not expose a strict extension. Do not weaken the solver or manufacture identities. Under the framework thesis, search for the lawful missing layer, branch, package action, continuation surface, or higher rung, guided by the negative result. Universality is a research orientation, not permission to falsify a run.

### 80. ★ Full integrated case
**Model answer:**

The statement mixes a scoped result with an invalid framework conclusion.

- The lower operator containing the mass does not by itself decide whether an SBT trace can be essential; SAU asks whether a lower-visible accepted replacement exists under the frozen profile.
- A feasible event package closes only the local-global event register. Predictive or macro-admissibility strictness may still exist.
- A large first predictive carrier may be a valid exact structural layer, not the final value layer.
- The framework permits towers and branches: an exact audit layer can feed a second task/scale carrier and a third run/value carrier.
- The next work must test lawful higher-layer packages, continuation admissibility, exactification, bounded-interface or budget separation, and complete channel factorization.
- At the same time, one must not call the ordinary transfer gap an SBT landing if the promoted carrier is bypassed or replaceable.

The correct conclusion is a typed, scoped status and a next lawful experiment—not “SBT is only audit vocabulary,” and not a fabricated obstruction.

# Critical cold-start canon

An agent is not ready for SBT work unless it can state all of the following without contradiction:

1. SBT is, by author-set framework identity, both meta-map and generative closure engine; it is not a black-box oracle.
2. Universality is an `[AUTHOR THESIS]`, not a theorem silently proved by every paper.
3. Formal scope disclaimers constrain theorem attribution but do not define away the framework thesis.
4. P1–P6 are typed closure mechanics; P3 alone is not directionality.
5. Fixed completion saturates; strict ascent requires package/theory change.
6. Definability is factorization; strictness is nonfactorization at a declared interface.
7. Event-package obstruction is one strict register, not the universal definition.
8. Related obstruction registers are not automatically equivalent.
9. Empirical identity compares lawful public responses, not labels or microscopic decompositions.
10. Hidden-record controls cannot expose higher-context joint answers to lower contexts.
11. The predictive quotient is minimal relative to declared continuations/readouts.
12. Promotion requires a representative-independent `U→U` law and second-stage stability.
13. Exactification removes decorative promoted coordinates.
14. In SAU, the value descends; the carrier is non-descending and essential.
15. Essentiality is deletion/replacement failure under a frozen lower profile.
16. Bounded interface and compression are hypotheses/results to test, not SBT guarantees.
17. A feasible or negative setup is a scoped verdict and a research redirect, not permission to alter the evidence.
18. Layer stacks may be towers or branches; the value need not land on the first strict rung.
19. No value may be read before strictness, promotion, controls, and the applicable value gate.
20. Papers and running code govern; syntheses and this answer key remain secondary.
