## Exact finite-continuation test and correction to the dispatch analysis

Let the exact positive base capacities be `c=(c_e)` and let `S` be the exact protected subspace inside the exact active-cut kernel. Step 3 constructed every basis vector `v in S` with

`sum_e v_e/c_e = 0`

in exact rational arithmetic. Therefore every affine displacement `delta=Vz in S` obeys the same equation. If `c'=c+delta` remains positive, define the exact positive ratios `x_e=c'_e/c_e`. Then

`sum_e x_e = sum_e (1+delta_e/c_e) = |E|`.

AM–GM gives

`prod_e x_e <= (sum_e x_e/|E|)^|E| = 1`,

with equality if and only if every `x_e=1`. Hence

`prod_e c'_e = prod_e c_e` if and only if `delta=0`.

This exact argument corrects the manager’s tentative expectation of a curve in the two-dimensional wheel subspace. Although one polynomial equation in two free coordinates generically defines a curve, here the base point is the strict global maximum of `sum_e log(c_e+delta_e)` on the positive affine protected plane. The equality level therefore contains only the base point. Dimension two does not evade the obstruction.

The implementation will reconstruct all six exact directions and their joint subspaces from pinned artifacts, verify exact tangency, positivity of the base, and linear independence, and emit the AM–GM certificate. It will not search numerically for a point ruled out by the exact proof.

1. terminal-label-fixed weighted graph isomorphisms, with nonterminal labels free;

## Preregistered independent bulk invariant

For any endpoint for which the declared closure saturates, define its **capacity-orbit multiset signature** as the lexicographically sorted set of exact sorted edge-capacity multisets over the complete terminal-fixed five-move orbit, enlarged by every finite per-edge reciprocal/basis-swap action. Internal tensor gauges and boundary-local unitaries do not change graph capacities; terminal-fixed isomorphisms only permute them; reciprocal swaps are explicitly quotiented; and starting from any member of a complete saturated five-move component yields the same enlarged set. Thus the signature is invariant under every generator of the declared gauge relation.

This invariant is independent of the boundary entropy vector and cut-fingerprint value, but it is explicitly relative to the declared gauge closure. A surviving candidate would require different signatures. Equal signatures would be typed `BULK_INVARIANT_FAILURE`. With no finite endpoint, both signatures and their comparison are `NOT_APPLICABLE_NO_FINITE_ENDPOINT`.
