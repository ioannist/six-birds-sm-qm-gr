# Six Birds v23 memory and grounding audit

## Executive verdict

The system contains valuable hard-won audit discipline, but it is **not safe as a cold-start auto-loaded grounding in its present form**. The chief problem is not incompleteness; it is that theorem-backed claims, primer doctrine, project hypotheses, implementation facts, workflow rules, and retracted historical conclusions are mixed together and repeatedly labelled **BINDING** or **grounded**.

The most serious consequences are:

1. SBT is simultaneously called a meta-map and a computational engine.
2. One strict-test register—`sixbirds_event` global-package obstruction—is made the definition of all strict extension in some files, while other files correctly recognize predictive and Cantor strictness without an event package.
3. Several typed obstruction registers are called globally equivalent although the papers prove equivalences only inside particular hypotheses and mathematical categories.
4. A Cantor-shell construction theorem is generalized into a universal recipe.
5. SAU essentiality is narrowed into a project-specific “dominant root must change” test.
6. Holonomy minimality is incorrectly paraphrased as “the exact predictive carrier cannot compress.”
7. A false Schwinger-mass landing and other retracted project claims remain in hard-loaded memory.
8. “Universality axiom: the obstruction is there” and “SBT has no dead ends” are not corpus theorems and directly conflict with Foundations I’s explicit scope statement.

**Immediate recommendation:** stop auto-loading the three most contaminated science memories, archive chronological/retracted material, and replace the hard-loaded core with a short typed canon carrying evidence-grade labels.

---

## What is already strong and should be preserved

The following material is valuable and broadly faithful:

- Authority disclaimers: papers govern theory claims; code and artifacts govern implementation claims; syntheses are secondary.
- The basic finite-lens factorization criterion for definability and strict refinement.
- Fixed-completion saturation: iterating one idempotent completion does not create a strict ladder.
- The SAU shape `U ↛_q`, `C(U) ↓_B a^♯`, including no-overread and no-smuggling.
- The distinction between witness positivity and promotion; promotion requires sufficiency, induced closure, second-stage stability, controls, honesty, and legibility.
- The requirement that induced transport be representative-independent and class-to-class.
- The descending-bypass and “verify the actual invariant, not the validator” disciplines.
- Bounded interface as an explicit modeling hypothesis, not a consequence of refinement.
- The honest statement that the corpus has not landed a measured physics scalar.
- The distinction between transport-null event identities and a genuinely predictive distinction.

The problem is that these correct points are embedded among stronger unsupported claims.

# III. Clarity redesign

## 1. Add evidence grades to every nontrivial sentence

Use one of:

- `[DEF]` paper definition.
- `[THM]` proved theorem with assumptions.
- `[SCOPED RESULT]` exact finite/audited-shell result.
- `[PRIMER]` interpretive doctrine, not theorem.
- `[CODE FACT]` verified implementation behavior.
- `[PROJECT HYPOTHESIS]` proposed transfer/application.
- `[WORKFLOW POLICY]` management rule.
- `[RETRACTED]` historical false conclusion.

A fresh instance should never have to infer the epistemic grade from tone.

Auto-load only a short canonical core. Put all round histories, retractions, and prior advisor proposals under `archive/` with no read-order link.

- theorem-backed SBT science;
- scoped paper results;
- code facts;
- project hypotheses;
- workflow policy;
- retracted history.

Once that separation is enforced, a reset instance should become substantially more reliable: it will still be anti-reductionist, but it will no longer be pushed into overclaiming strictness, guaranteed obstructions, nonexistent scalar landings, or false no-compression theorems.
